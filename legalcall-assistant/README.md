# 獭獭救场（LegalCall Assistant）

纯本地、离线、独立发行的 Android 应用。Kotlin + Jetpack Compose，包名 `com.legalcall.assistant`。

## 功能
- 话术自保：告知已录音 / 礼貌核实 / 要求书面函件（点击试听）
- 接听后自动播报：手动接听后自动外放话术（高级版，需授权"电话"权限）
- 一机一码本地激活：MD5 机器码校验 + 剪贴板自动静默验证
- 100% 离线：AndroidManifest 未声明 INTERNET 权限

## 构建
- Android Studio Ladybug（或更新），JDK 17
- 直接 Open 本项目根目录即可，Gradle 会自动拉取依赖

## 一机一码发卡流程
1. 用户点击"赞赏 1 元解锁"，App 自动复制 8 位机器码并跳转你的小红书
2. 你在私信收到机器码后，用发卡工具生成激活码发回：
   ```bash
   python3 tools/gen_code.py <机器码>
   ```
3. 用户复制激活码、切回 App，`onResume` 自动静默验证通过，解锁高级版

## 重要说明（务必读）
1. **自动接听无法实现**：Android 自动接听是系统特权（仅默认拨号器可用）。
   本应用实现的是"用户手动接听后自动外放话术"（PhoneStateListener 监听 OFFHOOK），
   不使用无障碍服务，规避平台滥用风险。
2. **"一机一码"是防白嫖，不是强加密**：盐值写在 APK 内，反编译即可破解。
   对 1 元定价，防住普通白嫖足够；要更强需上服务器校验，但那会失去"纯离线"卖点。
3. **小红书支付是人工流程**：跳转 + 复制是全自动，但收款/发码需你人工私信操作。
4. **语音用系统 TTS**：离线可用、无需打包音频文件（因此未走 MediaPlayer）。
5. **合规**：定位为"保护隐私、索要正规函件、引导合法沟通"。请勿在界面/文案中加入
   灰色敏感词，也不要将其包装为"反催收/逃债"工具对外宣传。

## 可调项
- 话术间隔：`CallMonitor.kt` 的 `SCRIPT_INTERVAL_MS`（默认 8 秒）
- 小红书 ID：`MainActivity.kt` 的 `XHS_URL`
